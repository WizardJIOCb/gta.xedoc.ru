# Palm Coast waterfront assets

The original facade photographs in `stores.jpg` and `office.jpg` are from Scouser, *Free Urban Textures: Buildings, Apartments, Shop Fronts*, released under CC0. The game crops and packs the images into two material atlases.

Source: https://opengameart.org/content/free-urban-textures-buildings-apartments-shop-fronts
License: https://creativecommons.org/publicdomain/zero/1.0/
The palm trunk albedo is *Palm Tree Bark* from Poly Haven, released under CC0. Source: https://polyhaven.com/a/palm_tree_bark
# Regional vegetation

The two-view tree and brush texture atlases were rendered for this project from Poly Haven's CC0 assets [Island Tree 01](https://polyhaven.com/a/island_tree_01) and [Shrub 02](https://polyhaven.com/a/shrub_02). The close roadside vegetation uses these photographic models as alpha cutouts.
