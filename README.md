# Palm Coast

Браузерная 3D-игра на Three.js. В миссии «Чужие ключи» герой забирает кабриолет на Pelican Keys и едет через острова к мастерской у городского пирса. За целый кузов платят $1000. На карте можно выбрать и собственный маршрут через болота Sawgrass Glades и придорожный посёлок Cypress Junction. [Играть](https://gta.xedoc.ru/)

## Локальный запуск

Для сборки нужен Node.js 22.12+ с npm.

```sh
npm ci
npm run dev
```

Игра открывается на <http://127.0.0.1:5483/>. В Windows файл `Играть.cmd` также умеет собрать игру и открыть её через локальный сервер Python 3.

## Управление

| Действие | Клавиши |
| --- | --- |
| Идти, вести машину | WASD или стрелки |
| Бежать, прыгнуть | Shift, пробел |
| Сесть или выйти | E у двери или в остановленной машине |
| Ручник, передать ключи у мастерской | Пробел, Enter |
| Повернуть камеру | Удерживать правую кнопку мыши и двигать мышь |
| Кулаки, направленный «Прибой», круговая «Нова» | 1, 2, 3 |
| Атака по курсору или по направлению камеры | Левая кнопка мыши или F |
| Сменить радиостанцию, переключить звук | V, M |
| Пауза с памяткой, чит-консоль | Esc, Ё (клавиша под Esc) |
| Карта побережья и выбор маршрута | Tab или нажатие на мини-карту |

В консоли команда HELP показывает список кодов. KEYS, GLADES, OUTPOST, MARINA и HAVANA переносят героя и кабриолет в выбранный район. HOME возвращает их к отелю Ocean Drive. FIX чинит кузов, NITRO включает форсаж, OVERCHARGE усиливает импульс, MIDNIGHT и SUNSET меняют освещение. На сенсорном экране доступны кнопки действий, а камеру можно вращать пальцем.

## Развёртывание

`npm ci && npm run build` создаёт статический сайт в `dist/`. На сервере Nginx раздаёт содержимое `/var/www/gta.xedoc.ru/current/`. Каждый релиз хранится отдельно в `releases/<git-sha>/`. Для обновления загрузите содержимое новой сборки в новый каталог релиза и атомарно переключите ссылку `current`. Пока предыдущая сборка сохранена, ту же ссылку можно переключить обратно.

Конфигурация виртуального хоста лежит в [deploy/gta.xedoc.ru.conf](deploy/gta.xedoc.ru.conf). Certbot использует webroot `/var/www/certbot` для проверки домена.

Источники и лицензии моделей и текстур находятся в `public/vehicles/`, `public/world/` и `public/surface/`.
